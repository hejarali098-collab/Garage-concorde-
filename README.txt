SITE GARAGE CONCORDE SÀRL

Contenu :
- index.html : page d'accueil
- devis.html : formulaire de demande de devis (ouvre l'e-mail du client)
- rendez-vous.html : lien direct Reservio
- styles.css / script.js
- dossier assets : logo, publicité et photos équipe

Pour publier gratuitement sur GitHub Pages :
1. Créez un nouveau dépôt GitHub (par ex. garage-concorde-site).
2. Envoyez tout le contenu de ce dossier à la racine du dépôt.
3. Ouvrez Settings > Pages.
4. Source : Deploy from a branch.
5. Branche : main / root puis Save.
6. GitHub fournit ensuite l'adresse du site.

Important :
- Le formulaire de devis utilise mailto: afin de fonctionner sans serveur. Après clic, l'application e-mail du client s'ouvre avec le message déjà rempli.
- Pour recevoir automatiquement des formulaires sans ouvrir l'e-mail, il faudra connecter un service de formulaire ou un petit backend.
- La section Avis Google contient un bouton vers la recherche Google. Un affichage automatique des avis nécessite un widget/API Google ou un service tiers.
